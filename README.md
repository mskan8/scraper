# 대한민국 상장주 시가총액 및 발행주식수 수집기

이 스크립트는 `pykrx` 라이브러리를 사용하여 KOSPI와 KOSDAQ 시장에 상장된 모든 종목의 시가총액과 상장주식수 데이터를 수집합니다.

## 사용 방법

1. **파이썬 설치**: 컴퓨터에 Python이 설치되어 있어야 합니다 (3.x 버전 권장).
2. **필수 라이브러리 설치**: 터미널(또는 명령 프롬프트)에서 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
3. **스크립트 실행**: 아래 명령어를 입력하여 데이터를 수집합니다.
   ```bash
   python fetch_stocks.py
   ```

## 결과물

실행이 완료되면 같은 폴더에 `stock_data.csv` 파일이 생성됩니다. 이 파일은 다음 정보를 포함하고 있습니다:

- **종목코드**: 종목의 고유 코드 (티커)
- **종목명**: 기업의 이름
- **시가총액**: 해당 시점의 총 시가총액 (원 단위)
- **발행주식수**: 상장된 총 주식 수

## 문제 해결 (Troubleshooting)

실행 중 `KeyError`가 발생하거나 데이터를 가져오지 못하는 경우:
- **날짜 문제**: 장이 끝난 직후나 시스템 점검 시간에는 KRX 서버에서 데이터를 불러오지 못할 수 있습니다. 잠시 후 다시 시도해 보세요.
- **네트워크**: 인터넷 연결 상태를 확인해 주세요.
- **라이브러리 업데이트**: `pip install pykrx --upgrade` 명령어로 최신 버전의 라이브러리를 사용 중인지 확인해 주세요.

*참고: CSV 파일은 엑셀에서 바로 열었을 때 한글이 깨지지 않도록 UTF-8-sig 인코딩으로 저장됩니다.*
