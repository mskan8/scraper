# 대한민국 상장주 시가총액 및 발행주식수 수집기 (FinanceDataReader 버전)

이 스크립트는 `FinanceDataReader` 라이브러리를 사용하여 KOSPI와 KOSDAQ 시장에 상장된 모든 종목의 시가총액과 상장주식수 데이터를 수집합니다. 기존 `pykrx` 라이브러리의 오류 문제를 해결하기 위해 더 안정적인 라이브러리로 변경되었습니다.

## 사용 방법

1. **파이썬 설치**: 컴퓨터에 Python이 설치되어 있어야 합니다 (3.x 버전 권장).
2. **필수 라이브러리 설치**: 터미널(또는 명령 프롬프트)에서 아래 명령어를 입력하여 필요한 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```
3. **스크립트 실행**: 아래 명령어를 입력하여 데이터를 수집합니다.
   ```bash
   python fetch_stocks.py
   ```

## 결과물

실행이 완료되면 같은 폴더에 `stock_data.csv` 파일이 생성됩니다. 이 파일은 다음 정보를 포함하고 있습니다:

- **종목코드**: 종목의 고유 코드
- **종목명**: 기업의 이름
- **시가총액**: 수집 시점의 총 시가총액 (원 단위)
- **발행주식수**: 상장된 총 주식 수

*참고: CSV 파일은 엑셀에서 바로 열었을 때 한글이 깨지지 않도록 UTF-8-sig 인코딩으로 저장됩니다.*
