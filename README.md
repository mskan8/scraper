# 대한민국 상장주 시가총액 데이터 수집기

이 스크립트는 KOSPI와 KOSDAQ 시장에 상장된 모든 종목의 시가총액과 상장주식수 데이터를 수집합니다. 현재 데이터뿐만 아니라 과거 특정 날짜나 기간의 데이터도 수집할 수 있습니다.

## 사용 방법

1. **필수 라이브러리 설치**:
   ```bash
   pip install -r requirements.txt
   ```

2. **현재 데이터 수집 (기본)**:
   ```bash
   python fetch_stocks.py
   ```

3. **특정 날짜 데이터 수집**:
   ```bash
   python fetch_stocks.py --date 20240102
   ```

4. **특정 기간 데이터 수집**:
   ```bash
   python fetch_stocks.py --start 20240102 --end 20240105
   ```

## 결과물

실행이 완료되면 `stock_data.csv` 파일이 생성됩니다.

- **종목코드**: 종목 고유 코드 (티커)
- **종목명**: 기업 이름
- **시가총액**: 시가총액 (원 단위)
- **발행주식수**: 상장된 총 주식 수
- **날짜**: 데이터 기준일 (YYYYMMDD)

## 데이터 출처 및 특징

- **현재 데이터**: `FinanceDataReader`를 통해 수집하며, 실패 시 **네이버 금융**을 스크래핑합니다.
- **과거 데이터**: `pykrx` 라이브러리를 통해 한국거래소(KRX) 데이터를 직접 가져옵니다. 휴장일인 경우 데이터가 수집되지 않을 수 있습니다.
- **Excel 호환**: CSV 파일은 엑셀에서 바로 열었을 때 한글이 깨지지 않도록 `UTF-8-sig` 인코딩으로 저장됩니다.
